00 // MISSION BRIEFING

One difference. Learn it well.

01

ENCRYPTION

A locked box

Encryption changes readable data into unreadable ciphertext. With the correct key, it can be changed back.

HELLO+ KEY →KHOOR+ KEY →HELLO
  • Reversible: yes, with the key
  • Purpose: keep information secret
  • Examples: AES, RSA, Caesar cipher
VS
02

HASHING

A digital fingerprint

Hashing turns data into a fixed-size fingerprint. It is designed to be one-way; there is no key to turn it back.

HELLO→3733cd…↛HELLO
  • Reversible: no
  • Purpose: check integrity or passwords
  • Examples: SHA-256, SHA-3 (MD5 is unsafe)
!

THE GOLDEN RULEIf you need the original data back, use encryption. If you only need to check whether data matches, use hashing.
